# Tisya Gupta – Resume Website 💛

A colourful, multi-page personal resume website built with semantic HTML5 and hand-written CSS (no frameworks, no JavaScript).
Created for the **IIMB HTML Mid-Term Assessment**.

🌐 **Live site:** https://tisyaaa12.github.io/resume---website-/
📁 **Repository:** https://github.com/Tisyaaa12/resume---website-

## About the site
A warm, "hearty" design with a coral, marigold, teal and plum palette, Google Fonts (Fraunces and DM Sans), a sticky navigation bar and a layout that adapts to phones, tablets and laptops.

## Pages
| File | What it contains |
| --- | --- |
| `index.html` | Header with name, tagline and photo; about me; work experience; education; skills and languages; achievements; positions of responsibility; interests |
| `projects.html` | Project Mirari, HandSpeak, the Life Unfiltered podcast, a published research paper and this website, with photo galleries |
| `hobbies.html` | Painting and guitar galleries |
| `certificates.html` | Table of certificates and letters, with click-to-enlarge scans |
| `contact.html` | Contact details, message form, FAQ and CV download |
| `style.css` | Shared stylesheet for all pages |
| `images/` | Project, hobby and certificate photos |
| `photo.jpg` | Portrait used in the header |
| `Tisya_Gupta_CV.pdf` | Downloadable CV |

## Highlights
- Semantic tags: `header`, `nav`, `main`, `section`, `article`, `figure`, `footer`, `address`, `time`, `mark`, `dl`, `details` and `summary`
- Tables for education, skills, achievements, certificates and projects
- Pure CSS lightbox for certificates
- Accessible: skip link, alt text on every image, reduced-motion support
- Responsive layout using CSS grid and flexbox

## Run it locally
Download or clone the repository and open `index.html` in any browser.

## Hosting
Deployed free with GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
