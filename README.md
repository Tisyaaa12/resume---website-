# Tisya Gupta – Resume Website 💛

A colourful, multi-page resume site built with semantic HTML5 and CSS.
IIMB HTML Mid-Term Assessment.

**Live site:** https://tisyaaa12.github.io/resume---website-/

## Pages
- `index.html` – header, photo, about, experience, education, skills, achievements, positions
- `projects.html` – Project Mirari, HandSpeak, research paper, this website
- `contact.html` – contact details, form, FAQ, CV download
- `style.css` – shared styles
- `hobbies.html` – painting and guitar
- `certificates.html` – certificates table and document gallery
- `images/` – all photos and certificate scans
- `photo.jpg` – my portrait
- `Tisya_Gupta_CV.pdf` – downloadable CV

## Deploy on GitHub Pages
1. Create a new **public** repository on GitHub (e.g. `resume-website`).
2. Upload all files (Add file → Upload files) and commit.
3. Go to **Settings → Pages**.
4. Under *Build and deployment*, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
5. Wait about a minute. The site goes live at `https://YOUR-USERNAME.github.io/YOUR-REPO/`.
